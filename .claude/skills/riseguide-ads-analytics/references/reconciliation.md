# Звірка з дашбордом і трекінг

**Дашборд Tableau «🇬 Google Perfomance» — джерело істини для команди.**
Якщо мій розрахунок розходиться — помиляюсь я, поки не доведено інше.

## Доступ до Tableau

Pod `https://prod-uk-a.online.tableau.com`, сайт `celebtableau9f1c5ed408`,
автентифікація через PAT (`claude-mcp`). **PAT деактивується після ~15 днів
невикористання** — конектор «раптом помер» → перше: перевипустити токен
(аватарка → My Account Settings → Personal Access Tokens).
Робоча в'юха для кампаній: «by campaign», фільтр Created Date = Today.
15.08 BigQuery і Tableau збігалися до цента — за замовчуванням BigQuery
(гнучкіші зрізи), «бери з табло» = тягнути з Tableau.

## Процедура при розбіжності

1. Не пояснювати розбіжність здогадкою. Витягнути дані самого дашборда:
   `Tableau:get-view-data`. Спершу перевірити **фільтри в'юхи** — 15.08
   «розбіжність» виявилась фільтром на кампанію в Grand Total, не формулою.
2. Взяти 5–10 кампаній і зіставити почленно (spend, purchases, метрика).
3. Шукати структурні підказки: від'ємні значення, точні збіги, різниця
   рівно на константу.
4. Розбіжність у спенді на 2–5% — нормальний лаг. Розбіжність у метриці
   на 100 п.п. — різні формули.
5. Висновок «дашборд помиляється» — тільки після почленної звірки.

## Контекст трекінгу (для розуміння джерел розбіжностей)

- Тегування: **Google Tag (gtag.js), не GTM.**
- Конверсії йдуть **server-to-server з BI-системи** (BigQuery), не з браузера.
- Enhanced Conversions for Web: активні, Automatic capture.
- **Атрибуційна модель у BI/CRM — невідома** (відкрите питання). Тому
  розбіжність BI ↔ Google Ads може мати непояснену причину — фіксувати,
  не вгадувати.
- Бізнес-модель: підписка; первинний KPI — CPA, ціль < $82 за покупку.
